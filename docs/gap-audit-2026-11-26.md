Need to build/verify all 7 packages (`libmusa, musa-sdk, libdrm-mtgpu, mtgpu-dkms, musa-toolkit, mtgpu-firmware, musa-runtime`) on all enabled chroots.

- IBT/CET: project docs already record objtool/IBT warnings from vendor core object; no IBT disabling performed. Keep this constraint.
- Secure Boot: not assessed in this session; DKMS/MOK flow documented in existing docs.
